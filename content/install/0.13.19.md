Fly 0.13.19 is the **C++ reference compiler**, frozen at this version. It
seeds the 0.14.x self-host, so you build it to rebuild the whole chain of seeds
from source (0.13.19 builds 0.14.x, 0.14.9 builds 0.15.x, and so on).
It builds with CMake.

Requires [CMake](https://cmake.org) 3.24 or later and a C++17 compiler.
The configure step downloads the precompiled LLVM 20.1.8 archive for your platform
from [fly-lang/llvm](https://github.com/fly-lang/llvm) into the build directory.

#### Linux

Install the build dependencies for your distribution:

```bash
# Debian / Ubuntu
sudo apt install build-essential libxml2-dev zlib1g-dev libtinfo-dev
# Fedora / RHEL / CentOS Stream
sudo dnf install gcc gcc-c++ make libxml2-devel zlib-devel ncurses-devel
# openSUSE
sudo zypper install gcc gcc-c++ make libxml2-devel zlib-devel ncurses-devel
# Arch Linux
sudo pacman -S base-devel libxml2 zlib ncurses
```

For stacktrace support (for debugging), also install `binutils-dev libdw-dev libdwarf-dev`
(Debian / Ubuntu) or `binutils-devel elfutils-devel libdwarf-devel` (Fedora / RHEL).

```bash
git clone --branch v0.13.19 https://github.com/fly-lang/fly.git
cd fly
mkdir build && cd build
cmake ..
cmake --build .
ctest                       # run from the build directory
```

#### macOS (Apple Silicon)

```bash
xcode-select --install
brew install cmake libxml2 zlib
git clone --branch v0.13.19 https://github.com/fly-lang/fly.git
cd fly
mkdir build && cd build
cmake ..
cmake --build .
ctest
```

#### Windows

Requires Visual Studio (MSVC) and [vcpkg](https://vcpkg.io). Only the C++ reference
compiler needs Visual Studio. The self-hosted releases from 0.14 onwards don't.

```powershell
git clone --branch v0.13.19 --config core.autocrlf=false https://github.com/fly-lang/fly.git
vcpkg install zstd:x64-windows
cd fly
mkdir build; cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_INSTALLATION_ROOT\scripts\buildsystems\vcpkg.cmake"
cmake --build . --config Release
ctest -C Release
```

The result is `build/bin/fly` (`fly.exe` on Windows).
